# T54 独立测试对象规格（未搭建）

对象名建议：`SweepLab`；状态 `SPEC_ONLY / NOT BUILT`。是隔离读数台，不是正式运动组件。

## 场景与读数

- 以线框显示球心、球半径、位移箭头；线框盒及半径扩张后的AABB（扩张角须用不同虚线颜色标明保守近似）；单侧平面画出自由侧法线箭头。
- 接触表每行读数：障碍稳定索引/名称、整步TOI[0,1]、推出前后中心、接触法线、近似接触点、穿透深度、剩余位移；结尾显示`blocked`、`stuck`、预算耗尽和几何复核标志。
- 另画解析最近点到原盒角/棱的距离对照，允许明确显示扩张AABB在圆角处早报，而非将其称为精确球盒。

## 可重复输入 / 失败 / reset

1. `Reset`恢复球半径0.5、障碍、起点/位移、接触预算、epsilon；清空历史路径/接触/状态灯。所有运行只用设置的固定数值步，不读取Unity时间。
2. 高速薄墙：盒 `[0,.1]x[-2,2]x[-2,2]`、半径0.5、从x=-20位移+100；期望中心止于x≈-0.5，不穿透。
3. 盒中静止初嵌：盒 `[-1,1]^3`、半径0.5、中心原点、位移0；最近扩张面距离应1.5m，稳定tie-break后推出到x≤-1.5-epsilon，接触深度显示1.5。
4. 平面静止初嵌：自由侧法线+X、d=0、r=.5、x=.25、位移0；推出深度.25并落至x≥.5+epsilon。
5. 多接触解析输入：起点(2,2,0)、位移(-3,-4,0)、r=0、墙顺序x=0/y=0；期望y先t=.5，x后整步t=2/3，不得重用无效旧输入(2,2)+(-3,-1)。
6. 单面法向完全阻挡：应`blocked=true, stuck=false`；单面纯切向滑动到预定终点：`blocked=false,stuck=false`。接触或剩余量为零本身不可判stuck。
7. 输入NaN、反向盒边界、零法线、负半径、无穷偏置应红灯`INVALID INPUT`且无接触结果；最大接触预算不足应显示未处理剩余位移与`stuck=true`。
8. 支持多次运行同一输入逐项完全一致；不同输入必须先Reset，不继承旧接触。

## 物理隔离 / 验收界限

- 轨迹、盒、平面用Gizmo/线框绘制；不添加Rigidbody/Collider/Trigger，不改Transform进行物理移动，不进入PVP/运动积分，不调用PhysX。
- 仅用数字执行T54候选。Unity/Udon编译、场景搭建、真实物理、VR、网络均未执行；此规格非搭建证据。
