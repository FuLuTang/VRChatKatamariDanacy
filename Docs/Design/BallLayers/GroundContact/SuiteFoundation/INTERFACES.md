# A 套最小边界与数据契约（草案）

> **DRAFT / 非冻结接口。** 这是本套 GroundContact、RadialProxy、Sweep 之间避免坐标/身份歧义的最小约定，不代替 T06 的跨模块冻结；也不替其他套选择算法、状态机或 Unity/Udon 表现形式。

## 共用坐标与数值约定（DRAFT；Unity 适配探针未过）

- 计算帧：单一共享世界数值坐标。当前想沿用 Unity 的轴标签 **+X 右、+Y 上、+Z 前**，但轴标签本身不等于“右手系”。Unity 2022.3 官方手册称其使用左手坐标系，且 `Vector3.Cross` 的方向明确按 left-hand rule；因此删除本接口旧稿的“右手系建议”断言。地图、球心、代理点、障碍边界必须在同一帧，不拿显示模型/Avatar本地帧作玩法坐标。
- 长度：接口边界暂以 **米** 讨论；参考代码没有单位换算，世界尺度仍待 T06，不代表已验证的 Unity 米制范围。
- 姿态：Python T50 以 `(x,y,z,w)` 执行明确的 Hamilton 主机主动旋转；T49 接收局部到世界、作用于列向量的 3×3 proper-rotation 矩阵（有限、正交、det≈+1）。这只是各自数学输入，不声明与 Unity `Quaternion` 的分量作用、`AngleAxis` 符号、乘法顺序或 `Vector3.Cross` 等价。不得只翻“手性”标签或盲目取反四元数。
- **集成前必过方向探针**：身份姿态的 +X/+Y/+Z 标箭头；分别记录主机与 Unity 2022.3 的 `Quaternion.AngleAxis(+90°, +Y) * +Z`、逆旋转和 `TransformDirection` 实测落轴；再用非对称点核对局部↔世界。差异须由显式适配映射解释并复测，禁止据此把 Python 直接接入 Unity。当前此探针仅有离线主机算例，Unity 实测 `NOT_RUN`。
- 平面：原始 `dot(n,x)=d`，归一化法线 `n` 指向允许球心存在的一侧；非单位 `n` 会连同 `d` 一起缩放。`d` 是带符号的法线坐标，不是 world-Y；平面最近原点锚点为 `d*n`。支持修正 `x' = x + n*delta` 保留切向分量，禁止将 `d+h` 当作任意坡面的 world-Y。
- 术语：核心半径 `r`、支持距离 `h`、球心位置 `x`、位移 `Δx` 不得混用；`h=max(r,max_i dot(-n,Q*p_i))` 是支持距离近似，不是完整动力学或精确凹凸碰撞。

## 三个模块最小输入/输出边界

### GroundContact

- 输入：有限非负核心半径；局部代理点集合（米）；有效旋转；世界平面 `(n,d)`；前一法线支持距离/位置；显式非负限幅参数。
- 输出：当前重算支持距离、受限的法线修正量/新球心位置、限幅标志。速度扰动如果保留，只能是带显式限幅的建议量；本层不积分速度、不决定接触材质、不负责碰撞次序。
- **回落语义**：支持高度是对“当前代理与当前姿态”的函数；输入代理移除或核心半径改变后应允许支持值降低。单步位置变化可另受向上/向下不同约束；向上限幅不能变成永不下降的历史最大值。如何平滑回落由调用方/产品参数另定，不在此拍板。
- 输出中的 `contact_point` 必须语义明确。平面锚点 `d*n` 不是球与实际地形的唯一接触点；若无法求实际接触特征，命名为 `plane_anchor`/`support_reference_point`，避免声称精确接触点。

### RadialProxy

- 输入：调用方确认可用于该球外壳的附着贡献；物件稳定身份、预烘焙局部或世界代理点、球位姿及可选的长物件候选标记。确认身份来源由上游决定；应可表示 `spawnId + spawnGeneration` 等稳定实例键，不能用数组下标、物件定义 ID 或短暂本地序号替代。
- 输出：固定/明确版本的方向集合、各方向支持长度、相对核心的突出量，以及可释放候选的有限摘要；本层不产生确认收益、拾取裁决、Renderer、物理 Collider 或掉落轨迹。
- 方向与长度转点：方向 `d_i` 必须是单位向量，长度 `l_i` 是非负米值，代理点是 `p_i=d_i*l_i`（同一局部/世界帧）。提供显式适配函数或在调用约定中等价执行；不要把长度直接当某个固定坐标轴分量。
- 多贡献：相同方向上存在多个物件/端点时，每个对象保留独立贡献；支持长度由当前仍附着贡献和核心基线重算，不得因移除一个最大贡献误删次大贡献，也不得只保留不可逆累计最大值。
- 掉落/释放：对象离开球壳时，上游确认其身份和状态变更，本层原子移除该对象对采样方向与极值候选的贡献。是否在世界中坠落及其新位置不属于代理职责。候选可拒绝、显式释放或按上游明确的策略替换；不能隐式丢弃贡献或无报告驱逐。

### Sweep

- 输入：共享世界帧内的球心起点 `x`、本步线段位移 `Δx`（米）、非负球形判定半径、障碍几何、接触预算及分离容差。
- 输出：已验证路径上的最终球心、未消耗位移、接触时间/法线/稳定障碍身份（若提供）、以及可解释的卡住/恢复状态。`TOI` 是当前剩余线段的参数 `[0,1]`；若需要对外报整步归一化时间，适配层须转换并说明。
- 初始嵌入处理独立于“是否有位移”：即使 `Δx=0` 也要能检测并报告/按明确策略修正穿透；修正深度必须真正到达自由侧，而不是只推一个 epsilon。多个约束连续投影后仍须复测，不可把已碰撞后的剩余线段视作未经检查即可通过。
- AABB 先扩半径得到 Minkowski AABB 是保守快速近似，盒角处会提前/误报；**不得称为精确球-盒碰撞**。精确圆角距离需要另一种几何计算；本套不规定其实现。
- `stuck` 不应等价于“剩余位移为零且发生过接触”：单面阻挡入射分量、但仍有可行切向移动，是正常滑动/停止，不足以证明陷阱。状态名与阈值需要由本层定义并以可行域/位移 oracle 验证。

## 身份、确认与错误策略

- 来自拾取/账本的身份以稳定实例键和世代作键；只有上游确认的附着记录能进入权威代理构建。纯客户端预测可在隔离副本中预览，不能与确认代理、分数、PVP 判定合并。身份映射由上游所有者确认，本接口不定义其权威协议。
- 每次调用先完整校验输入；非法输入采用明确失败（Python 草案用 `ValueError`，Unity/Udon 适配需映射为调用方可识别的失败码/无效结果），不可静默替换成零值、身份复用或部分写入。attach/rebuild 失败应保持旧代理状态不变；测试应检查失败原子性。
- 拒绝：NaN/Inf、错误维度、零/非单位且不可规范化的方向、负半径/长度/间隙、退化/非法旋转、空或重复稳定键、无效 AABB 边界、非正限额、越界接触时间。可安全归一化的非零向量/四元数需在文档中明示并统一处理。
- 数值运算中间值也要检查溢出/非有限结果；仅检查原始参数并不保证点积、距离、法线变换之后仍有限。浮点容差应随米制尺度校准，不在此设最终游戏阈值。
- 出错时回报原因/调用上下文；不继续用损坏几何推进路径。模块不捕获并吞掉异常来伪造成功，不承担跨层回滚；若一次处理多个贡献，先验证完整批次再提交，保证失败原子性。

## 非目标

本契约不冻结方向采样数、极值候选上限/淘汰策略、支持回落平滑、抬升/分离上限、摩擦/反弹、TOI 同时碰撞优先级、真实球-盒精确解、PVP 球形半径、数据网络格式或 Udon 实现。上述值仍是 DRAFT，需要各自证据与正式接口审批。
