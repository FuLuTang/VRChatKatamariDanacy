## 1. 一句话

一只被大王点名的屎壳郎，推着一颗会越滚越大的球，从沙土小径滚过干草堆、菜园、牧场、果园和农具棚；它吃下去的每一件农场杂物都会长到球上，最后要滚出一颗能让大王满意的球。

## 2. 设定与故事钩子

### 2.1 法布尔给的事实（可核，转述不用原文引语）

- 让-亨利·法布尔（Jean-Henri Fabre）在《昆虫记》（*Souvenirs entomologiques*，十卷，1879–1907）第一卷里用整章写圣甲虫（*Scarabaeus sacer*）：它把粪搓成球，用**后腿**推着走，头朝下、屁股朝上。
- 法布尔记下的几件事，正好是玩法的原型：球是**食物储藏**（推进洞后慢慢吃）；球可以**比甲虫本身还大**；两只甲虫会**抢同一个球**；育幼的球是**梨形**（他叫它 "la poire"）。
- 古埃及把这种甲虫（khepri）和**推着日轮的太阳神**联系在一起。这是本文借用的唯一神话层：不是宗教内容，只是一个「推球」的视觉母题。

### 2.2 我们加的一层（虚构）

真实粪球只有几厘米，我们的球从 **0.30 m** 起步，这是**大王的球**，不是生物学。这个尺度差要在美术上说得通：

- 场景按「甲虫视角」搭：草叶像树、土粒像石头、木栅栏像城墙；
- 球不是粪，是**晒硬的土球/材料球**——棕褐色、干燥、表面有草屑和沙粒；不做湿润、不做苍蝇、不做气味梗。恶心感是我们要主动避开的。
- 球长大了会**带上吃掉的东西**：这是「块魂」的视觉语法，也是我们唯一的成长反馈。

### 2.3 「大王委托」怎么接（提议，不改现有剧情文本）

现有剧情模式文本只定义了三件事：**大王房间**、结算时**「呈给国王」**、按球径给**星**（见 [StoryMode README](../../StoryMode/README.md) §状态机、[HUB_LOOP_PLAN](../../StoryMode/HUB_LOOP_PLAN.md)）。它没有给任何主题写委托文案。所以这里只给**可选文案**，不写成已定事实：

| 委托名（提议） | 一句话 | 星级口径（沿用现有：球径） |
|---|---|---|
| 「把太阳推回来」 | 大王要一颗圆得能当太阳的球；滚到目标直径就算推到 | 现有三档球径 |
| 「草甸清道夫」 | 牧场堆了太多碎料，滚一遍就算清完 | 同上，不加计数目标 |

## 3. 空间布局

### 3.1 区域骨架

- 单区域 **24 × 24 m**（与 [REGION_MAP_PLAN](../REGION_MAP_PLAN.md) 的 PicnicCorner 同级），单 spawn、单条主环线、两条对角捷径。
- 出生点在**南侧巢穴口**（沙土堆），面向北；主环线**顺时针**，走完一圈回到巢穴口。
- 中心留 **6 × 6 m** 的「晒场」空地，是唯一能看清球长大过程的开阔地，也是最后一段的加速区。
- 高度差 ≤ 0.25 m，全部可推上去；没有跳跃、没有台阶高于 0.20 m。水槽边沿是例外（0.35 m，需要球长大后才上得去）。

### 3.3 尺寸门与路线

设计上 8 道门，对应 8 个球径档（0.40 / 0.55 / 0.75 / 1.00 / 1.25 / 1.60 / 2.20 m）；门的物理形态是**能推开的木栅门 / 石墙缺口 / 倒下的木杆**，不是空气墙。**注意：运行期今天只有一道绝对 1 m 门**（`PickupAbsorbMath.cs:140-141`、`KatamariBallMotor.cs:113`），本文的门是设计意图，未实现（同 [REGION_MAP_PLAN](../REGION_MAP_PLAN.md) 的结论 (h)）。

两条对角捷径用**倒下的木杆 + 干草捆**封住，球够大时可以直接吞掉抄近路——这既是奖励，也是「吃穿墙」的第一次演示。

### 3.4 容器/支架的两段式

草甸的「容器」不是箱子，是**农场设施**：水槽、饲料槽、干草架、手推车、蜂箱、梯子、麻袋堆。规则统一：

1. 球小的时候，它们是**地形**（挡路、可绕、可当掩体）；
2. 球够大之后，它们是**一件可吞物**（整件消失，球上挂一个缩小的它）；
3. 它们上面**先摆着小件**（谷粒、草料、铃铛、鸡蛋）——所以「先吃上面的，再吃容器」是自然的顺序，不需要教程。

这条链在 `catalogue.csv` 里用 `parent_support_id` 表达：**72 行**的 parent 指向 12 个 t7 行（7 个地标 + 5 个可吞支架）。

## 8. 危险与不可吞

- **不可吞**：地面、石墙主体、老橡树、棚屋墙体、水槽基座、远山、天空盒、所有 t7 里标 `structures_landmarks` 的「房体」件。
- **半可吞**：水槽沿、饲料槽、蜂箱、手推车、草垛——球够大才整件消失，之前是地形。
- **没有伤害**：本项目没有血量、没有敌人、没有失败惩罚；「危险」只有**卡住**（窄缝、球大于通道）和**时间**。所以本文不设计掉落伤害、不设计追逐。
- **卡住自救**：所有窄缝 ≥ 1.2 × 最大球径，或者一端封死（死路）但不窄于 1.5 × 球径；死路尽头放一件可吞物，吃掉就能掉头。
- **避讳**：不做蛆、不做苍蝇、不做新鲜排泄物、不做腐烂特写；粪球一律称「土球」，材质干燥、颜色偏土黄。
