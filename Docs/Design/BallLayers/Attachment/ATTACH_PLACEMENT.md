## 1. 现象与根因

所有者看到两件事，机制不同。

| 现象 | 机制 | 位置 |
|---|---|---|
| **A. 道具悬在球面外一段距离** | 吸收触发的距离是球心到道具**枢轴**，阈值 `reach = 碰撞半径 + contactRadius(0) + 道具自身盒的外接球半径`；放置是原样冻结触发那一刻的世界位姿。外接球比细长/扁平的盒子大得多，盒子的实体没碰到球就已触发 | `PickupAbsorbMath.TryComputeReach`（`Runtime/Pickup/PickupAbsorbMath.cs:364-387`）；`KatamariBallMotor` 吸收评估（`:3797-3801`）；`PickupFieldHost.AttachProp`（`Runtime/Pickup/PickupFieldHost.cs:1266-1331`） |
| **B. 红球芯大片可见** | 视觉球按 0.95·r_phys 画并**随体积长大**，先吸的道具被包进红球，没有任何重定位；件数少、件小/薄 | `BallView.cs:93-145`（`useVisualCoreRadius` 默认开）；`BallShapeMath.TryVisualCoreRadius` |

**A 的量化 (离线模拟)。** 蟹座小院 432 件可吸道具，球沿随机水平方位逼近、首次进入 reach 的那一步放置（道具按文件里的原朝向），量道具盒表面到物理球面的距离：

- D=0.222 m（起始球）：中位 **1.2 cm**，p90 **5.2 cm**，最大 **8.4 cm**；>1 cm 占 56%，>3 cm 占 20%，>5 cm 占 11%。D=0.28 m：p90 5.3 cm，最大 9.9 cm。
- 按种类的中位：牙刷 4.4 cm、筷子 4.1 cm、抹布 3.7 cm、牙膏 2.7 cm、剪刀 2.6 cm（起始球）；0.28 m 球下风铃 8.6 cm。这就是所有者图里牙膏管、小物件离球面一段距离。
- 另有两项同方向的误差：视觉核心只有 0.95·r，相对**看得见**的球面还要多悬一截；`AttachProp` 在吸收事件之后的 `Update` 才跑，期间球继续推进，一部分件反向陷进去（定步 0.02 s，球速 1–2 m/s 时每步 2–4 cm；R30 全程平均约 0.35 m/s，峰值没有记录）。两个方向的误差都留在冻结位姿里。
- **R30 数据的局限**：R30 日志（`/tmp/r30_autopilot_log.txt`）记直径/累计件数和待吸槽的中心距 `d`，**没有吸附瞬间的盒到球面距离**；`PEND@15` 里 `toothbrush_001 d=0.62` 等是待吸槽，不是吸附点。所以悬空幅度目前**只有离线模拟，没有 Unity 实测**。
- 所有者图里不是每个道具都已吸附：左下的螃蟹、牙膏管、剪刀不少躺在地上（道具运动程序还没有运行时宿主，见 `CANCER_COURTYARD_DIFFERENCES` D04）。球附近哪些在 `AttachmentRoot` 下，要在 Unity 里看层级才能判断（O1）。

**B 的量化 (读图 + 离线模拟)。** 所有者今天的图（球径约 0.28 m，目视 ~20 件）：红色像素约 1976 px，红色区域包围盒 61×72 px，按竖向直径估圆盘红可见约 49%，按横向估约 68%（遮挡使圆盘直径不确定，只当量级）。离线模拟（现状放置、随机朝向、就近吸收、真实 `growthMm3` 定价、3 个随机种子均值）吸 10/20/30 件时红可见 72% / 51% / 41%，量级与所有者的图一致。**起因不是“视觉球比碰撞球大”**（视觉球 0.95·r，不大于物理球）。

## 3. 现行设计

### 3.1 吸附位置：触发即接触，原地冻结

- **触发改为“道具盒碰到球的碰撞体”**（`CANCER_COURTYARD_DIFFERENCES` D08，absorb-gate-dims 在做）。触发时道具实体已贴着球的碰撞面，所以**不需要放置修正**：`AttachProp` 继续“原样冻结吸附瞬间的世界位姿”（换算成球局部位姿、写局部位姿、登记径向代理），朝向不动，**不加埋入偏移**，不拉入，不重定位，不缩放，允许与已吸附件互相穿插。A 的根因随 D08 消失。
- 本项不改 `AttachProp` 的放置语义；它只在 D08 落地后才与原作一致。D08 之前观感 A 仍在。
- **冻结的是触发那一刻的相对位姿**：现状 `AttachProp` 在事件环消费时才读球心（见 §1），球在事件到消费之间继续推进，会让件相对触发时多陷 `v × 延迟`。若 Unity 日志（§6 U1）显示这一项超过 5 mm，应在吸收提交时记下球位姿快照随事件一起给宿主（小改动，属实现者）。
- **吸附瞬间的星爆特效**（原作约 0.07–0.13 s，接触点处）：记为**需求**，属以后的美术/特效项，本轮不做。

### 3.2 球芯显示尺寸：固定为起始球径

- **视觉核心直径 = 本关起始球径，整局不变，不随吸收长大**（原作录像 b1；替代之前 `0.95·r_phys` 随体积长大的口径）。起始球径来自关卡（蟹座 0.222 m；`startDiameterWorldM`，未设时由 `startVolumeMm3` 推出），与 HUD 在回合开始时显示的数相同。
- **碰撞、接地、吸收门所用的等效体积球照旧随体积长大**（`r_phys = cbrt(3V/4π)`）；吸附发生在这个球的接触面上，所以大球时物件在固定核心**之外**成一层外壳，中间留空洞（原作 30 cm 时同样如此）。
- 这就是原作的观感机制：核心被盖住不是因为核心大，而是因为后吸的件一层层压在外面。
- **核心外观**：原作核心是按尺寸分档换的低模“杂物团”（`core_01…21`），不是光滑红球；起始期（核心大面积可见）读成“一颗红球粘了几件东西”正是这个原因。核心材质/网格是美术项（`PARITY_AUDIT` 视觉核心行，undecided），与本规则无关；本规则只定它的**尺寸**。

### 3.3 埋没 / 消隐

**不做。** 核心固定后，物件永远在固定核心之外，“整个件被核心包住”的情形不存在，没有可隐藏的东西；先吸的件被后吸的盖住，仍然画出（原作也如此）。体积、账本、已吸附表、径向代理都不动。

原作的相对大小显示层级（专利 d1–d3）**默认不做**，因为它会隐藏小件、让球更秃；只在 Quest 上已吸附渲染器数超预算时再启用，阈值没有原作数，届时单独测。

### 3.4 对碰撞 / 接地 / 径向针代理的影响（离线估算）

**吸收判定与接触 v2 不受本项影响**：核心常量只改视觉；碰撞、墙、台阶、爬升仍读 `r_phys`；吸收体积门读语义直径不变。

**核心固定后的接地视觉**是需要回答的问题：外轮廓约为等效直径的 1.15 倍时，道具会不会明显插进地面，径向针代理（16 向、cap `min(0.35·r, 0.30 m)`）能不能托住。离线估算（蟹座 432 件可吸件，nearest-first 吸收，真实 `growthMm3`；每件在盒刚触到物理球时放置并再陷入 0–2 cm（一个定步），朝向相对球随机（球滚动），3 个随机种子；吸到 D=0.30 / 0.50 / 0.80 m）：

| 量 | D=0.30 m | D=0.50 m | D=0.80 m |
|---|---|---|---|
| 已吸附件数 / `r_phys` | 24 / 0.150 m | 86 / 0.251 m | 192 / 0.400 m |
| 固定核心（Ø0.222 m）占 D | 0.74 | 0.44 | 0.28 |
| 固定核心可见（投影，12 方位均值） | **30%** | **4%** | **0%** |
| 外轮廓半径 / `r_phys`（p10 · 中位 · p90，随机朝向球面方向） | 1.33 · 1.46 · 1.57 | 1.36 · 1.55 · 1.94 | 1.42 · 1.59 · 2.1–2.7 |
| 物件越过物理球的深度，即“插地”深度（中位 / p90 / 单种子最大，cm） | 6.9 / 8.7 / 11 | 13.7 / 23.6 / 27 | 24.5 / 61.5 / 94 |
| 针代理 cap `min(0.35 r, 0.30)`（cm） | 5.3 | 8.8 | 14 |
| 现规则下能进代理的长物件数（最长边 ≥ 0.5·D 且长宽比 ≥ 2.5） | 0 | 0 | 2 |
| 按现规则（≤4 个长物件）代理托住后的剩余插地（中位 / p90 / 最大，cm） | 6.9 / 8.6 / 11 | 14 / 23.7 / 27 | 22–27 / 44–70 / 63–94 |
| 假设代理收**全部**吸附件（16 向、cos 衰减、cap 同上）后的剩余插地（中位 / p90，cm） | 3.1 / 5.3 | 7.2 / 17.2 | 15.4 / 52.0 |
| 朝下方向上“整体离地”（轮廓小于 `r_phys`）的方向占比 | 0% | 0% | 0% |

读法：

1. **核心可见度与原作吻合**：核心 / 球径 ≈ 0.74 时可见 30%（原作 6.9 cm、比 0.72：35–50%）、0.44 时 4%（原作 9.7 cm、比 0.52：10–20%）、0.28 时 0%（原作 12.7 cm、比 0.39 起为 0）。固定核心本身就复现了“10–13 cm 起红色看不见”。
2. **会明显插地，而且今天已经如此，不是核心固定造成的**：插地深度由“件在物理球外伸出多少”决定，与核心大小无关；今天的放置更靠外（reach 壳），只会更深。D=0.30 时中位 6.9 cm（约 0.46 r），D=0.50 时 13.7 cm，D=0.80 时 24.5 cm（中位）。
3. **现有径向针代理托不住**：它只登记 ≤4 个“长物件”（最长边 ≥ 0.5 倍核心直径、长宽比 ≥ 2.5），0.30/0.50 m 一件都没有、0.80 m 两件，对插地没有贡献；即使 cap 放开到收全部吸附件，0.30 m 能托一半（剩余 3 cm），0.50/0.80 m 仍剩 7/15 cm（p90 17/52 cm）——因为 cap 是 `0.35·r`，而我们的件相对球偏大。**所以接地视觉要靠原作那种“针模型覆盖所有吸附物”，不是靠现有 4 个长物件代理。**
4. **轮廓比原作大**：我们的外轮廓中位 1.46–1.59×`r_phys`，原作约 1.15（0.9–1.3）。差在件相对球更大（定价/内容，见 `/tmp/ball_audit/visual_report.md` 与 O6）；原作录像还见 30–60% 的嵌入（弱证据），我们按 Lead 决定触发即接触、不加嵌入，轮廓因此偏大、凸出更多。这不是缺陷判定，是 Unity 验收轮要看的量（U5、U6）。
5. 外轮廓 p90 在 0.80 m 到 2.1–2.7 倍，来自极少数大件（体积门允许至球体积的 10%，几十厘米的长件径向戳出）；这类件正是 `maxProxyProtrusionWorldM = 0.30` 与长物件代理设计的对象。

**对策（Lead 2026-11-17 已定，已实现）：针模型覆盖全部吸附件。** 每件吸附物把它的 8 个盒角点对 16 向针做增量 max 合并（约 128 次点积，无每帧成本），最远角点没越过核心 `minProxyProtrusionM`（1 cm）的件忽略；cap `min(0.35·r, 0.30 m)` 与 `maxProxyLiftPerStep` 暂不改，**PROVISIONAL**。v1 每步取 16 根针的针尖进接地求解，v2 把针尖当扫掠段进接触，`CompactNeedleCap` 因此升到 16。cap 后剩余插地的离线估算（与上表“全部吸附件”行同一模型，3 个种子均值）：D=0.30 / 0.50 / 0.80 m 为中位 3.1 / 7.2 / 15.4 cm，p90 5.3 / 17.2 / 52.0 cm，最大 7.8 / 21.6 / 72.2 cm；对比不收针时的 6.9 / 13.7 / 24.5 cm（中位）。是否放宽 cap 与抬升上限、会不会出现“被凸出物顶得颠”的手感，仍是所有者决定（O8），先看 U5。
