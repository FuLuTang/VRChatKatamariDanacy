# P14 品牌候选与宣传门禁准备

本目录是内部研究资料，不代表最终命名、商标结论或对外宣传批准。

- [`names.csv`](names.csv)：5个原创名候选及中文/日文读音草案、查询字段、歧义与语言审校状态。
- [`evidence.md`](evidence.md)：公开免费搜索记录、可重跑查询链接、被读取页面、检索边界与概念邻近风险。
- [`promotion_rules.md`](promotion_rules.md)：概念图、素材/Blender技术图、Unity实机画面、多客户端/性能声明各自的证据级别与标注规则。
- [`handoff.md`](handoff.md)：工作范围、未做项与后续门禁。

## 读者注意

精确名称搜索未见结果不等于可用、可注册或无权利冲突。本包没有进行商标数据库、法律清权、公司名、应用商店、社交账号或域名全面检查。日文读音和中/日语意译未经母语者审校。当前没有最终选定名称；用户仍需挑选方向并批准。

**公开边界**：内部“VRC塊魂”只作为项目内部/参考称呼；公开定位应为独立滚球/甲虫主题，不复用官方角色、名称、标志、音乐或专属美术。当前不得宣称已推出、设备已兼容、不晕、性能通过、多人稳定或收费商城开放。
