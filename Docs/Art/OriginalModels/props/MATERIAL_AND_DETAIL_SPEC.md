# 材质与细节升级规范（2026-11-15，Lead 下达）

> 背景：owner 看过 80 件 pilot 的预览后指出「相当多太简略、材质没用上」。实测：**80 件里 32 件只有 1 个材质槽、44 件 2 个、4 件 3 个**，且多数主色亮度 > 0.7（纯白/浅灰），所以远看是一片白。
> 本规范是这一轮返工的唯一标准，按它改，不要各写一套。

## 1. 硬规则（不满足就是不合格）

1. **每件 ≥ 2 个材质槽**；主体 + 一个明确的功能件（盖/把手/印刷面/金属件/带子）。hero 件（球、杯、瓶、盒、乐器类）≥ 3 个。
2. **必须有一个暗色槽**：线性亮度 ≤ 0.12（用于缝隙、印刷、橡胶、深色金属）。没有暗色 = 没有层次。
3. **主体色线性亮度 0.30–0.65**；**不允许任何槽亮度 > 0.88**（纸可以 0.80–0.86，但必须配暗色印刷槽）。
4. **材质对比**：同一件内任意两个槽的亮度差 ≥ 0.15，或色相差 ≥ 60°；否则视为同一槽。
5. **粗糙度按材质**：金属 0.28–0.40、陶瓷/釉 0.30–0.45、塑料 0.40–0.55、木 0.70、纸/布 0.85–0.95、土/石 0.90。
6. **不许纯白 (0.95+)**、**不许纯黑 (0.0)**；不许高饱和荧光色（sRGB 饱和度 < 0.85）。
7. **无贴图、无 UV、无透明**——颜色即材质。印刷图案用**几何薄片/凹槽 + 暗色槽**表达，不要写字母或数字（避免品牌/IP）。

## 3. 每类形状的「加细节」清单（至少做一项）

- **扁平纸类**（stamp/ticket/postcard/doily/sticky_note）：加**印刷块**（暗色薄片，0.3 mm 凸起或凹陷）+ 一条折痕/压线；邮票要有**齿孔**（凹口不是锯齿）。
- **块状包装**（matchbox/candy_bar/pill_box/tissue_box/pizza_box）：加**分模缝/开盖缝**（1–2 mm 深槽一圈）+ 一块**深色标签面** + 一个圆角差异（顶盖比盒身小 1 mm）。
- **圆柱容器**（mug/bowl/bottle/jar/can）：**内壁用更暗的槽**、口沿做 1 mm 翻边、底部圈足；瓶加**标签环带**（比瓶身深一档的整圈）。
- **工具/餐具**（fork/knife/spoon/opener/pen/pencil/brush）：金属件与手柄**必须两色**，交界处做 1 mm 台阶；刃口/齿尖用更亮的金属槽。
- **软体**（sock/t-shirt/wool/slipper/chip_bag）：主色布 + **包边/罗纹**用暗一档；褶皱用 2–4 条浅凹槽，不要只靠轮廓。
- **食物/自然物**（egg/grain/acorn/nut/leaf/clover/feather）：一个主体 + 一个**局部异色**（果脐、叶脉、斑点、羽轴），不许整件单色。
- **玩具/电子**（toy_car/controller/remote/earbuds/battery/keychain）：深灰机身 + **彩色按键/贴片** + 深色屏幕/窗口；按键要有 1 mm 凸起。

## 4. 面数

允许在 `catalogue.csv` 的 `tri_budget` 基础上**最多 ×1.6**（仍不得超过档位硬上限：t0 300 / t1 400 / t2 500 / t3 700 / t4 900 / t5 1200 / t6 1800 / t7 3500）。超了先砍细节，不许破壳。

## 5. 验收（作者自查）

1. 每件 `closed_shells == 1`、非流形 0、零面积 0、n-gon 0。
2. 用 `view_image` 看预览：**能一眼分出至少两种颜色/明度**；白色件必须有暗色印刷/缝隙。
3. 把该组 20 件的 contact sheet 看一遍：**整张不能是一片白/一片灰**。
4. 在 REPORT 里逐件写：槽位列表（key + 亮度）、加了什么细节、面数变化。
