- **需纠正**：代码第 59 行以完整位移范数作角度，包含法向分量；滚动只应由相对支撑平面的切向位移产生。第 62 行取 `displacement × normal`，旧测试沿用同一符号，接触点无滑动检验未建立。用同一右手叉乘语义举例：平地 `n=+Y`，球心向 `+Z` 移动，接触半径 `ρ=-Y`；正确角速度轴为 `+X`，使 `v+ω×ρ=0`。当前 `+Z × +Y=-X`，代入接触点速度与球心速度同向，表明原符号在该约定下反了。若适配到不同引擎帧，须先验证变换，不得只按这一个标签盲目取反。
- **非法初始姿态**：`VisualRollState.local_rotation` 可由调用端直接构造任意值；`advance()` 最后归一化乘积，但零四元数会导致除零异常，非有限四元数可污染运算。需要构造/入口校验、显式恢复或拒绝策略，及失败不改旧态的测试。
- **长时累计**：当前每步把结果规范化（有助稳定），但没有大量小步 vs 合并角度的对照、范数漂移/有限性、接近边界轴切换或符号连续性测试。需独立核验长序列，不以一次 `norm()` 返回自身作为完整稳定性证明。
- **瞬移**：当前只看单段 displacement，无传送标志或重定位基线机制；位置跃迁可能让球狂转。调用端应明确重置步，需测试重置前后不把跃迁距离累加进姿态。

## 标准库 Python 独立测试策略

所有期望从接触点运动学、几何、状态不变量或独立矩阵表达导出；不要用被测实现自己的叉乘/四元数 helper 推导 expected。当前旧测试只是兼容基线。测试尚未在本轮运行，也未增补。

### VisualRoll oracle

1. **接触点无滑动符号**：在一个明示的适配帧中，地面 `n=(0,1,0)`，球心切向位移 `Δp=(0,0,s)`、`s>0`、时间 `Δt>0`，半径 `r>0`。由刚体接触点速度 `v_contact = v_center + ω×ρ` 且 `ρ=-r n`，零滑动要求 `ω×ρ=-v_center`；解得正角速度方向 `+X`。再对 `+X` 轴、`θ=s/r` 作独立 3×3 小角度矩阵/接触点有限差分，验证接触点位移抵消球心位移；旧 `d×n` 结果应被该 oracle 检出反向。反向 `Δp=-Z` 时方向反号。
2. **斜坡任意切向**：构造单位 `n` 与 `Δp` 含法向和切向分量；由投影几何独立算 `t=Δp-n·dot(Δp,n)`、`s=|t|`。法向位移变化不应改变转角；纯法向移动不应滚动。令 `t` 趋近零，输出应稳定且不生成 NaN/随机轴。
3. **角度与半径**：固定支撑法线，数条纯切向直线位移；从表面标记/解析接触关系检查 `θ=s/r`。距离 `2πr` 回到同一姿态（允许四元数 `q` 与 `-q` 等价），但此等式只测幅度，不代替轴符号 oracle。
4. **非法姿态与原子性**：初始四元数测试零、NaN/Inf、错误长度、极小非零范数、非单位合法姿态。每种明确拒绝或规范化并可观察；拒绝后对旧姿态快照相等，不允许半更新。非单位输入规范化后不得改旋转方向。
5. **累计稳定性**：由解析旋转矩阵/轴角生成大量小步和等价的一次总步作比较；检查每一步分量有限、范数有界、局部 scale 始终 1，方向误差在明示容差内。再反向走回同一路径，姿态回到初始等价旋转。该测试只支持数值性质，不代表 Udon 性能或头显体验。
6. **重定位**：调用显式 reset/teleport 路径前后位置跳变巨大；新姿态应不增加与跃迁距离成比例的角度，后续连续的小位移重新开始正常滚动。阈值分支需单测边界和非法阈值。

### FollowRig oracle

- 最短偏航：从 `359°` 追向 `1°` 和从 `1°` 追向 `359°`，独立取圆周短差分别为 `+2°/-2°`，不能经过长路径；滤波输出在短弧之间且无 overshoot。
- 重生/瞬移：给定新位置/yaw 与显式标志，输出按规定立即重置/重新起滤波，旧球位置不参与长距离插值；普通更新则继续平滑。
- 高度：构造低于/处于/高于上下限的目标球位姿，期待值由直接 `min(max(value,lo),hi)` 的几何约束定义；测试 `lo>hi`、NaN/Inf、负/倒置参数明确拒绝。测试只涉及虚拟 rig 偏移，不模拟 HMD。
- 输入不变性：改变传入的球视觉 roll/pitch 或模拟自转完全不改变 rig；更优的新接口根本不提供这些参数，验证输入/输出结构边界。

### RemoteProxy synthetic oracle

- 在测试夹具中合成确认键（例如上游提供的稳定 event ID + generation），给两种不同到达顺序的相同事件集合，比较最终按稳定键排序的表现状态；重复投递不增加活跃实例/Renderer。
- 同 ID 不同摘要拒绝并报告冲突；旧世代、已清场、过期摘要不能复活；切换回合/世代按明确作用域隔离。期望键由 fixture 预先定义，不通过模块本地计数生成。
- 超预算只影响 renderer/装饰数量，不改变输入确认摘要集合、账本哑对象或碰撞哑对象；清场后预算回收。测试名/输出需标 `synthetic`，未接 T51 不出真实接线结论。
