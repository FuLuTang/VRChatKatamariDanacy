## 如何使用

1. 发布/冻结任何原作规则前，先看 evidence_status。`official_text_confirmed`／Tier 1 官方口径（含制作人采访）明示的有限事实才算确认；Tier 2 玩家实机与 Tier 3 wiki 只做交叉印证（`strongly implied`）；公开文档未回答即 `unknown`，不能用经验、旧作或AI推断补齐。
2. 对 unknown，可先按项目已明确方向构建可调方案；若项目规格尚未由用户/主管选择，维持待定，不将候选数值硬编码。
3. 每一选择列出单位与证据边界：几何长度用共享世界米，分数/收益使用各自账本单位，时间用秒；无已知值时写`unknown`，不填零或伪装实测。
4. 任何需参考游戏实机的新结论，需要获准、可复核的版本/模式/步骤/录像时间点。任何项目体验阈值需先由用户/主管确定，然后用对应真人/多人门禁验证。
5. 项目首发目标仍是两图；一图方案只是待批准的范围变更，见 [P17 RFC比较](../../Archive/Preparation/ReleaseRFC/comparison.md)。本目录不修改根任务或任务状态。

## 关键规则状态（已决 / 仍未决）

T01与第二轮研究已确认的原作规则主干：KatamariBall为4人对战；计分必须把球送进场景内的交分区（「変換エリア」／玩家称「ポイントエリア」；在王子飞船正下方、约每60秒换位并显示导航图标属 Tier 2/3 强暗示），交分是**用体积换分、球会变小**（不是回到初始球），球太小不给分；被更大的球撞到会被吞、短暂不能动并在别处重生，**没有淘汰**，同尺寸弹开、可吞更小的对手；对战有宝箱道具（变大或妨碍对手）与加分Brother；结算另有3个项目各给第一名+50pt。**2026-11-14 用户已就交分与回合规则拍板**（见 [OPEN_DECISIONS 的「交分与回合规则」小节](../../OPEN_DECISIONS.md)）：交分按比例缩小而不是回初始体积（`post = max(start, start + (pre − start) × 0.25)`，`residual = 0.25`）、最小兑换球径 `0.55 m`、兑换区 60 s 四台轮换（激活 0/60/120/180 s，180 s 单局只用 3 个窗口，下局起点 +1 台偏移）、结算采用原作 3 项各 +50pt 奖励层作为第二层（交分仍是唯一主计分通道）。这些数值全是 **PROVISIONAL 项目值**，不是原作测得值；[decisions.json](decisions.json) 已回填对应条目。
仍 `unknown`（均指**原作**）：单局时长、回合数、体积→积分换算公式、原作的最小兑换体积数值、对战道具完整清单与数值、地图数量/出生点/补给。项目 180 秒单局、单槽磁铁/火箭、KO 约 3 秒＋保护约 2 秒、1.35 尺寸比等仍是未验证原型值，不是对原作细节的认证。详见 JSON 并在接口冻结前由主管审阅。
