# 乱房间（MessyRoom）

> 状态：`PROVISIONAL_NOT_TESTED`，2026-11-15。本文是第四张图的**内容与空间提案 + 首批道具目录**：没有在 Unity 里建场景、没有跑过布局、没有实机。
> 范围：主题设定、区域级空间骨架、类别、尺寸阶梯、地标、配色、危险物、158 件首批目录（机器可读版在同目录 `catalogue.csv`）。
> 非目标：不改 `Runtime/`、不改关卡 JSON、不改 `tasks.json`、不决定许可、不做美术精修、不承诺排期。球体物理、吸收规则、关卡定价不归本文。

## 1. 一句话

一个人住久了的房间，地上、桌下、床底、柜顶全是东西。你是从床底滚出来的一团毛絮，越滚越大，最后要把整个房间卷回「刚搬进来那天」的样子。

## 2. 设定与故事钩子

### 2.1 球是什么

**球是一团灰尘毛絮（dust bunny）**。这是本图与其它图最本质的区别：不是工具、不是玩具、不是粪球，而是**房间自己长出来的东西**。

- 起手 0.30 m：卡通化的「一大团」，由头发、棉絮、纸屑压成，表面毛糙、颜色灰白偏暖；
- 它滚过地毯会变大，滚过地板会沾上碎屑，滚过床底会勾出袜子——**成长就是打扫**；
- 它不吃「干净的东西」：所有可吞物都是「被放错位置的东西」，这条规则让「乱」成为可玩的资源，而不是背景。

### 2.2 为什么会长大

毛絮球的体积来自**粘住的东西之间的空隙**：现实里灰尘球越滚越松，我们的球越滚越紧。所以它在视觉上是「一团越裹越大的杂物」，而不是「一个光滑的球」。这给了美术一个明确方向：**球面永远不光滑**，始终挂着上一秒吃进去的东西。

### 2.3 「大王委托」怎么接（提议，不改现有剧情文本）

现有剧情模式只定义**大王房间**、结算**「呈给国王」**、按球径给**星**（[StoryMode README](../../StoryMode/README.md)、[HUB_LOOP_PLAN](../../StoryMode/HUB_LOOP_PLAN.md)）。本图的可选委托文案：

| 委托名（提议） | 一句话 | 星级口径（沿用现有：球径） |
|---|---|---|
| 「回到搬进来那天」 | 大王要看看这房间空着是什么样；滚到目标直径就算「收完了」 | 现有三档球径 |
| 「你到底攒了多少东西」 | 大王好奇一个人能攒多少；球越大越体面 | 同上 |
| 「找那只丢了很久的袜子」 | 袜子在某个支架上；顺路滚大就行，不做单独拾取 | 同上，但需要一件「目标物」摆在场景里 |

三条都只改文案，不改状态机、不改评分。选哪条由所有者决定（§11）。

## 3. 空间布局

### 3.1 区域骨架

- **1:1 真实尺度**的单间公寓：**12 × 8 m**，层高 2.7 m。不是 ToyRoom 那种「巨人房间」——本图的差异在**内容**（成年人的生活痕迹）而不是尺度把戏。
- 单 spawn：房门内侧（西南角），面向房间中心。
- 主环线**逆时针**贴着墙走一圈（家具都靠墙），中间是**地毯空地**（3 × 4 m），也是唯一适合观察球长大的地方。
- 床底是**低矮通道**（0.28 m 净高）：0.30 m 的球进不去，0.40 m 之后才能钻——这是本图第一个「长大才能去」的空间，比尺寸门更自然。
- 高度差 ≤ 0.45 m（床、沙发），全部可推上去；桌面 0.75 m 需要球 ≥ 1.0 m 才能上（用倒下的椅子/纸箱堆当坡）。

### 3.3 尺寸门与路线

设计 8 道门（0.40 / 0.55 / 0.75 / 1.00 / 1.25 / 1.60 / 2.20 m），物理形态是**能推开的门 / 移开的纸箱 / 床底净高 / 桌上高度**，不是空气墙。**运行期今天只有一道绝对 1 m 门**（`PickupAbsorbMath.cs:140-141`、`KatamariBallMotor.cs:113`），这些门是设计意图，未实现。

主环线一圈约 **28 m**；两条捷径：从床底钻过去（球 ≥ 0.40 m），或从桌上横穿（球 ≥ 1.0 m）。两条都不是必须的，但都能省 6–8 m。

### 3.4 容器/支架的两段式

房间的容器是**家具**：书架、衣柜、抽屉柜、洗衣篮、纸箱堆、床、书桌、暖气片。规则与草甸一致：

1. 球小：是地形（挡路、可绕、可当掩体）；
2. 球大：整件可吞，球上挂一个缩小的它；
3. 上面/里面**先有小件**（书、袜子、盘子、线材）——先清小件再吃支架，是自然顺序。

`catalogue.csv` 里 89 行的 `parent_support_id` 指向 12 个 t7 行。

## 8. 危险与不可吞

- **不可吞**：墙、地板、天花板、窗玻璃、门框、暖气片管道、镜子、吊灯。
- **半可吞**：衣柜、书架、书桌、床架、沙发、洗衣篮——球够大才整件消失。
- **没有伤害**：没有血量、没有敌人、没有失败惩罚。「危险」只有卡住与时间。
- **卡住自救**：床底净高 0.28 m 会让 0.30 m 的球卡住——这是**故意**的第一次「进不去」，但必须是「进不去」而不是「卡死」：床底入口做成斜边，球会自动被推出来。
- **避讳**：不做脏乱到恶心的程度（不做过期食物特写、不做虫害、不做排泄物）；「乱」是生活痕迹，不是卫生灾难。
