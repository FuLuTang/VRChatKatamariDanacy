# P14 宣传证据门禁与素材标注规则

> 用途：后续概念、美术预览、游戏截图及多人/性能宣传的内部检查表。不是对外宣传文案、实现状态或发布批准。

## 素材类别必须分开

| 类型 | 允许展示的证据 | 必须标注/允许文案 | 禁止推导 |
|---|---|---|---|
| **概念图 / 主题提案** | 仅表达构图、角色气质或玩法愿景的插画/草图；现阶段不生成新图。 | 显著写“概念图 / CONCEPT ART / イメージイラスト；非游戏画面 / NOT GAMEPLAY”。 | 不当作已实现功能、实际地图、Avatar造型、UI或截图。概念稿不能证明舒适、兼容、性能或多人稳定。 |
| **素材/Blender技术图** | 资产检查渲染、尺寸/轮廓/代理可读性图；若日后制作，需关联资产包、来源/许可证、文件哈希、渲染工具和检查目的。 | 写“资产审查预览 / ASSET REVIEW RENDER；非Unity画面、非实机 / NOT IN-GAME”。 | 不等于最终美术方向、Unity导入验收、实际碰撞、物件可拾取或宣传成品；不得把隔离目录里的预览拿去营销。 |
| **Unity真实画面** | 仅来自可核对的项目构建/场景，在用户允许和参与者授权下实际捕获；保存构建版本、场景/模式、日期、捕获方式及必要的裁切/后处理说明。 | 只有确为构建捕获，且未改变玩法结果时，才可标记“实机”。修图/合成/AI润色需披露；画面有未实现占位则标清。 | 单张截图不能证明功能可用、网络同步、多人对局、兼容设备、帧率或通过验收。不得用概念渲染覆盖为实机。 |
| **多人、兼容性、性能声明** | 多客户端测试日志、实际平台/设备、构建版本、场景与可复现步骤；性能另需机器配置、采样方法、样本数和P50/P95/P99等完整测量记录。 | 声明精确限定测试条件、版本和日期；明确未测范围及异常。多人宣传须授权所有可识别参与者。 | 不可把计划、空模板、模拟器、单人画面或静态渲染写成多人/性能/设备兼容证据。任何单一测试条件都不能外推所有用户设备。 |

## 当前可说 / 不可说

### 当前允许的内部表述
- 这是一个**独立滚球/甲虫主题**的VRChat世界设计提案；玩法方向与公开名称仍在准备阶段。
- 内部候选名只作为讨论选项，不出现为正式品牌或商店名称。
- 项目文档中的PCVR + Desktop是**目标范围**，不是“已支持”或已实测兼容的承诺。Quest不在首版目标范围；也不能宣称Quest支持。
- 可以写条件性规划：“计划先验证……”“概念设想……”“待实际构建和多人测试”。

### 当前不可用于公开宣传的声明
- “已经推出/即将上线/现在可玩”，除非确有已发布构建和用户批准。
- “PCVR/某头显已兼容”“支持所有控制器”“4人稳定对战”“高帧率/优化完成”等，除非各自有对应的平台、多人或性能证据。
- “任何人都不晕”“舒适无眩晕”“电竞级公平”或其他绝对体验承诺。
- “收费商城已上线/已可购买/购买可获得某权益”。商家资格、Listing、官方权益、真实交易恢复及用户发布批准均未通过；付费店铺保持关闭。
- 以“致敬”名义复用官方名称、Logo、角色、音乐、音效、标志性画面或专属美术；不得把竞品或参考作品素材拼入概念。

## 出门前审查清单

1. 每个候选名称来自 `names.csv`，标为未定提案；展示前检查最新公开检索记录和母语反馈。
2. 素材身份与权限有据可追：来源URL、作者/权利主体、许可证全文/版本、资产文件、处理、署名和允许使用范围。网页上的“免费”标签不代替文件/许可审阅。
3. 按上表标注概念、资产技术图、Unity实机截图，不能混用证据级别；裁切、合成、生成填充和AI润色均须记录。
4. 功能、平台、玩家数、性能、舒适性与收费分别核对各自的验收门禁；一个类别通过不代表其他类别通过。
5. 拍摄包含私人Avatar、玩家姓名、语音或可识别信息时，先取得参与者同意；不录制用户未授权内容。
6. 任何上传、发布、商店修改、外部发帖均须用户明确批准；本工作包不执行这些动作。

本工作包只形成文本规范和公开网络名称候选研究。未创建图像/封面/UI/音视频；未运行Blender或Unity；没有游戏截图、多人测试、兼容性、性能、舒适性、支付或发布证据。相关声明仍 **NOT_RUN / NOT_ESTABLISHED**。
