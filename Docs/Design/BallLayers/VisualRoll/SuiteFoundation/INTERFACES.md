# C 套最小边界与接口草案（DRAFT / 非冻结）

仅定义 T53 VisualRoll、T55 FollowRig、T56 RemoteProxy 的套内责任和交换语义。T06 未完成，以下不是冻结 API，不规定相邻套实现、Unity/Udon 类型/容器或传输协议。

## 全套共用适配约定

- **世界帧**：项目共享世界坐标，世界 **+Y 向上、+Z 向前**；所有位置/位移/半径均以 **米**表达。当前契约没有在本草案强制定义跨 API 的手性名称。坐标帧转换要显式适配，不能只改“左/右手”标签或盲目翻转叉积/四元数。
- **旋转**：外部语义为旋转四元数 `(x,y,z,w)`。输入必须是 4 个有限分量且范数大于数值下限；策略可选择在入口归一化，但必须记录规范化状态。零/非法初始姿态不得直接使用。累计后定期或每步规范化；阈值/频率仍待误差测试，不设产品常数。
- **旋转矩阵适配**：若某 API 内部用 3×3 矩阵，适配器必须声明“矩阵如何作用到列/行向量、存储次序、组合先后、局部到世界方向、坐标帧手性”；对有限性、正交性及 `det≈+1` 检验，不接受带缩放/镜像的矩阵冒充纯旋转。用有名方向探针验证：+Z 前向绕 +Y 偏航的结果、单位轴旋转、矩阵/四元数同姿态。不得臆定 Unity API 的矩阵存储或乘法方向。
- **输入合法性**：每个操作先校验完整输入和中间运算；拒绝 NaN/Inf、错维、半径非正、dt/限值负值、退化法线、非法姿态和数值溢出。Python 宿主可用 `ValueError`/明示错误码；运行时适配由调用方映射为可观察失败，不得吞错后伪造零姿态或成功状态。需要状态更新时先算候选，再原子提交。
- **精度**：几何容差以米表达，四元数/偏航容差以弧度或角度明确写出；不得拿一种容差代替所有平台。最终容差需由独立 oracle 与目标运行时确定。

## T53 · VisualRoll（仅表现）

- **输入最小语义**：相邻两次已确认的球心世界位置差 `Δp`；选定的有效支撑法线 `n`（世界帧、指向自由空间）；正有限滚动半径 `r` 米；有效当前表现姿态/是否显式重置标记。法线来源/多接触择一归调用方，不能从模型碰撞或账本反推。
- **切向量与角度**：`t = Δp - n·dot(Δp,n)`；纯表现滚动距离 `s = |t|`，角 `θ=s/r` 弧度。法向位移不贡献滚动。若 `s` 接近零，姿态保持。
- **轴的符号不得靠公式自证**：利用接触点速度独立验方向。在一个明确声明叉乘/旋转约定的适配帧里，设接触半径向量 `ρ=-r n`、球心切向速度 `v_t=t/Δt`，候选角速度 `ω` 必须满足 `v_t + ω×ρ = 0`，等价接触点瞬时速度为零。以该方程/数值有限差分测试轴符号，不以被测代码生成的 `cross()` 结果作 oracle。由于不同坐标变换约定可能翻转表达式，先固定和验证引擎帧，再映射；不承诺未经测试的叉积顺序。
- **输出**：候选局部/世界表现旋转增量及新姿态；BallVisualRollRoot 的缩放恒 `(1,1,1)`。不得写 BallPhysicsRoot 平面朝向、位置/速度、账本、玩法碰撞、FollowRig 或镜头。
- **瞬移/重定位**：调用端须提供 teleport/reset 信号，或基于明确上限分类为不连续位置跃迁；该步只重置上次位置基线（和可选的姿态基线），不按瞬移距离累计旋转。阈值由集成者的运动步长/重生语义另定，不在这里造数。
- **错误与恢复**：非法初始四元数应显式失败，或在明确标记的初始化边界采取单位姿态并报告恢复；普通更新不可静默将损坏姿态归零。长序列规范化后须有限、范数约 1，并保持尺度 1。可疑法线切换/接近零切向步应避免不确定轴跳变，策略由调用者/模块测试定。

## T55 · FollowRig（独立水平参考架）

- 输入仅为 BallMotion/调用方提供的世界位置、**水平朝向标量**（或等价水平单位方向）、时间步及显式重生/瞬移标志；眼高和上下限作为由上游调校的参数输入。
- 只读水平 yaw；不读取球自转、roll/pitch、HMD 姿态、头部位置或输入设备观察轴。T46 旧式 `(roll,pitch,yaw)` 整组姿态不是新接口，抽取时只接其平面 heading 语义。
- 输出独立 FollowRig 的目标/滤波位置与 yaw；不成为 VisualRollRoot 子节点，不改球状态。偏航滤波应沿最短圆周差值处理 0/360° 边界；目标角归一化，数值有限。
- **重生/瞬移**：由明确标志选择立即重置到新参考位置/yaw、重启平滑基线，避免跨地图长插值或瞬时大旋转。普通连续更新保留滤波。标志传播缺失不能被“自动猜测并通过”掩盖；如何推断长跳变留作适配层兜底。
- **眼高限制**：相对球/参考体的竖直偏移限制在调用者明确给出的有限合法区间；最小值不高于最大值，眼高/目标位置有限。限制的是表现架，不是球、玩法坐标或用户真实 HMD 身高。范围由平台体验/T05 与 T06 决定，本套不选默认值。

## T56 · RemoteProxy（只读确认摘要的视觉消费者）

- 当前只允许用**合成的确认摘要**离线模拟输入/输出与资源预算，不称已接正式事件流。拟议字段只包括有界显示所需的稳定球身份/世代、摘要修订/确认事件身份、少量装饰种类/种子、必要的世界位姿/可见性提示；最终模式/字段待 T51 及 T06 正式契约。
- 稳定身份必须原样来自上游权威确认记录；本模块不得按本地到达顺序自行递增或伪造序号，不得用列表索引、Renderer ID 或随机值当身份。无确认摘要则拒绝/忽略并报告，不猜测。
- 消费器语义需支持重复、乱序、旧世代、跨局切换、移除/清场，并对同一确认身份幂等；同 ID 不同摘要视为冲突并可诊断，不能静默覆盖。旧世代数据不能复活为新物件。具体 revision/去重窗由确认接口所有者定义。
- T56 单独拥有远端 renderer 可见性、上限、回收/显隐预算；受预算时只丢弃/合并纯装饰表现，不改变已确认摘要、尺寸/价值账本、玩法碰撞或球状态。不得写账本、物件玩法状态或 Collider。
- **真实接线条件**：等待 T51 提供经确认且稳定的附着身份/摘要输入，并经契约评审；本草案与合成测试不完成 T56 正式接线，也不表示 T56 已完成。

## 明确拒绝/一致性与非目标

拒绝空/重复/冲突身份、非法世代/修订、非有限位姿/四元数、非法半径/dt、超预算输出被误报成功、错误版本混拼及未经标记的输入不连续。模块失败不得部分更新姿态/代理集合。错误类型和 Udon 可表达载体由实现层映射，不假定 Unity 运行时可抛异常。

不在 C 套定义拾取/账本/确认序号生成、物品附着位姿所有权、玩法碰撞和运动积分、镜头/HMD适配、Netcode、渲染资产/固定预算数值、Udon 容器/API 或最终跨模块协议。
