## 4. 不用浏览器操作的素材路线与安全闸

1. 作者官方页面/官方API → 明确免费及许可 → 页面与获取方式证据。
2. 下载只落 ignored intake；拒绝账户/付费/验证码/绕过授权。遇到此类站点列为后续人工候选，不浪费时间伪造直链。
3. 收到归档先列目录和大小，不执行解压内容；检查绝对路径、`..`、符号链接、重复路径、加密、压缩膨胀、代码/插件/安装器。
4. 包内LICENSE、SHA256、下载日期、作者、用途与源文件分发许可分别记录。网页CC0标签不自动等于整个包无例外。
5. 如需读取LICENSE，只读目标成员并限大小；不将陌生Python/C#/Blender脚本装进工具链。
6. 实际文件名映射到物件需求，记录缺少哪些物件。模型尺寸、单位、UV、面数、材质健康未查就写unknown。
7. 工具扫描通过 ≠ 许可人工接受 ≠ Unity导入通过 ≠ 游戏可用；正式导入仍须T02/T20相关门禁。
8. 用户尚未选定最终下载方案，因此试点有硬上限；不批量下载，不将原始资产公开推送，不自行指定项目LICENSE。

- 开工：读取共享任务最新版，写范围检查，模型实际核验，指明输入文件与验收。
