# Picnic candidate manifest (prescreen)

[`picnic_candidates.csv`](picnic_candidates.csv) lists 36 proposed discrete picnic-scene object concepts and intended gameplay/scene use. The concepts are a design shortlist, **not a verified inventory** of any pack. Package file presence, package LICENSE text/path, and SHA-256 are all unknown until package-level review. Public page license claims and evidence gaps are documented in [`../../AssetIntake/license_gaps.md`](../../AssetIntake/license_gaps.md).

The shortlist follows the initial map progression in `Docs/03_MAPS_ASSETS.md`: small seeds/fruits, medium foods/tableware, larger basket/pot/stool props. Item size tiers are provisional design suggestions, not measured gameplay values. Distinguish collectible objects from fixed landmarks/decor during map design.
