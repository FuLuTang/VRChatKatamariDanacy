# A 套交接：现状、缺陷与独立 oracle

状态：离线源码准备；本套基础文档交付，不是 Unity/Udon 实现或验收。检查对象是现有 host-side Python 草案和旧单测。按本次写入边界，仅新增本 `SuiteFoundation/` 下文档；未修改三个模块或其旧测试。

## 可保留的基线

- **GroundContact**（`Docs/Design/BallLayers/GroundContact/ground_contact.py`）：支持函数按球半径与代理投影取最大值；会将非零平面法线归一化；限幅速度扰动/上抬；原点平面锚点对一般单位法线以 `d*n` 表示。作为待修 host 参考基线可保留，不是经过独立全面验证的物理解算器。
- **RadialProxy**（`Docs/Design/BallLayers/RadialProxy/radial_proxy.py`）：保留每物件端点，删除时对受影响方向重算；候选有数量限制；重建先创建临时实例再替换状态，失败前不覆盖旧实例；世界点到球局部用四元数逆旋转。方向格、半球邻域与候选管理仍属草案。
- **Sweep**（`Docs/Design/BallLayers/Sweep/sweep.py`）：连续平面扫掠、扩张 AABB 的线段测试、剩余位移投影和稳定输入序号打破同 TOI 平局可保留为保守基础。AABB 膨胀仅是盒角保守近似，不是精确球-盒碰撞。

## 需修缺陷（对照代码，不是猜测）

### GroundContact

1. `proposed = max(previous_support_height, support)`（当前第 66 行）使支持距离只能保持或增加；代理变短、长杆脱附、核心变化都不能使球落下，产生永久悬空。重新定义“当前几何支持值”与“本步向上/向下位置变化限幅”，不让历史 max 冒充当前支持值。
2. `visual_rotation` 被直接传给 `_mat_vec`，但函数未验证 3×3 形状、元素有限、正交性/行列式。短行会被 `zip` 静默截断；比例/镜像矩阵会当作旋转使用。增加畸形矩阵拒绝及矩阵/四元数适配器测试。
3. 法线归一化与偏置必须成对处理。当前 `_normalize(ground_normal)` 后原样使用 `plane_height`；若调用方把偏置按未归一化的原始法线给出，平面会被错误移动。入口应定义 `d` 的语义：统一接受单位法线/对应 d 并拒绝未单位法线，或归一化 n 时同步把 d 除以原法线长度。不能只测 d=0 的非单位法线。
4. 点乘支持距离的平面数学与输出语义需区分：`core_center_height = plane_height + corrected` 是法线坐标，不是任意斜坡的 world-Y 高度；`contact_point = d*n` 是平面最近原点锚点，不是由代理极值求出的实际接触点。保留斜坡切向坐标时应以 `n` 沿法向修正；不可把锚点叫精确接触点。
5. 仅检查原始标量/代理点有限；旋转矩阵乘法、点积和支持计算的中间溢出/非有限值需要检测。空/错维输入应拒绝，不能静默容忍。

### RadialProxy

1. **多贡献验证缺口**：当前每方向重算遍历所有已附着端点，原则上用 max 保留次大贡献；旧测试却未独立验证同方向多物件竞争后移除最大贡献仍保留次大值。新增 oracle 覆盖；不要把局部方向索引缓存误当每个方向只属于一个物件。
2. **候选释放/序列稳定性缺口**：`detach` 删除同 ID 候选，但 `candidate_ids` 使用字典插入次序，重建输入换序会改变序列。需独立验证释放后容量恢复，另明确候选输出是否按稳定身份排序；满额拒绝/替换仍由接口所有者定，不允许静默驱逐。
3. **掉落语义边界**：`detach(item_id)` 只从球代理删贡献，不计算世界掉落/新位置。这应保留为本层边界；上游确认离附着后调用，不将未确认本地预测送进权威代理。
4. `attach` 校验某些几何后才提交，但数量/数值极端、四元数/世界坐标中间运算、stable ID+generation 以及批次失败原子性没有充分覆盖。确认键不得只用数组序号/定义 ID。
5. 当前没有“方向×长度→点”的显式适配接口。必须验证单位方向 `d`、长度 `l` 后形成 `p=d*l`，避免把长度塞入任意轴。

### Sweep

1. `sweep_sphere` 循环第 142 行先因位移长度很小退出，因此**零位移初始嵌入永远不检查**，不能恢复静止时的穿透。
2. `_box_hit` 检测球心在扩张 AABB 内时第 105 行返回的 penetration 恒为 0。扫掠层随后只推 `separation_epsilon`（第 164 行），远不足以越过扩张边界；旧测试的盒中心输入应明显暴露此缺陷。需要返回到最近自由面的实际穿透距离并做可验证分离。
3. `stuck = remaining≈0 && displacement!=0 && contacts`（第 181 行）把正常的单平面阻挡/法向速度归零误判为卡住；应把“完全被阻挡/已停止”与“没有可行切向方向的陷阱/卡死”区分，按可行运动 oracle 验证，不能仅凭残余为零。
4. 盒半径膨胀 AABB 在角落是方形外扩，会对真实球-盒圆角产生保守假阳性；明确记录为近似，不以“精确球盒”表述。
5. 旧 `test_multiple_contacts_keep_distance_order`（测试第 28–34 行）起点 `(2,2,0)`、位移 `(-3,-1,0)`；y 终点为 `1`，线段上 y 始终非负且未到第二面 `y=0`。当前 x=0 首次接触后投影掉 x 分量，剩余 y 仅再走 1/3，仍远未到 y=0。断言存在第二接触、时间为 1 没有几何依据。**先改测试输入/预期，不为旧断言改扫掠算法。**

## 独立 oracle 测例建议

这些期望值来自解析几何/集合重算，不复制被测实现的循环或中间公式；所有用例仍需真正加入模块测试并运行。

### GroundContact

- 水平面 `n=(0,1,0), d=2`，`r=1`，局部点 `(0,-3,0)`，单位姿态：支持距离 `3 m`，新球心法线坐标 `5 m`；平面锚点 `(0,2,0)`。斜坡测试要保留任意切向分量，并验证中心沿法线位移，不将 `5` 误当 world-Y。
- 同一几何中先有端点伸出至 `h=3`，后移除端点，当前支持应回到球芯 `h=1`；设置有限回落策略时，本步位置按策略下降。只允许上抬的老用例仍测上抬限幅，不再把它当唯一方向。
- 单位旋转将代理点转至与法线相反方向时解析投影增量应为已知值；分别用四元数与等价旋转矩阵输入应一致。非正交/错误维矩阵和 NaN 输入明确拒绝。

### RadialProxy

- 对任意固定单位方向 `d`，独立构造两个同向贡献 `pA=2d`、`pB=4d`，另加核心半径 `r=1`。预期该方向支持 `4`；移除 B 后为 `2`；再移除 A 后为 `1`。重建时反转物件输入顺序，所有方向值相同，候选身份列表若对外暴露则顺序须符合明文稳定规则。
- 方向/长度适配：`d=(0,0,1), l=2.5 m` 得点 `(0,0,2.5)`；非单位、零方向和负/非有限长度拒绝或依文档先显式规范化。
- 四个候选满额后移除其中一个，应可显式加入新候选；失败的非法 attach/rebuild 后读取快照与旧状态，应与操作前完全一致。离附着只删除球壳贡献，不测试世界掉落位置。

### Sweep

- **零位移平面嵌入**：自由侧 `n=(1,0,0), d=0`，`r=.5`，球心 `(0.25,0,0)`、`Δx=0`。解析穿透深度 `.25 m`，恢复后 `x>=.5`（含显式分离容差），且报告接触/恢复；不可因位移为零直接空返回。
- **扩张盒嵌入**：盒 `[-1,1]^3`、`r=.5`、起点原点。扩张边界各面距中心 `1.5 m`；最近面恢复至少移动 `1.5 m + epsilon`（等距时按稳定 tie-break）。只推 epsilon 后仍在扩张盒内即失败。该期望是保守扩张几何的分离，不宣称真实圆角精确碰撞。
- **有效顺序双接触**：平面障碍按 `(x=0,y=0)` 排序，起点 `(2,2,0)`，位移 `(-3,-4,0)`，`r=0`。先到 y 面，`t=1/2`；投影后剩余 x 位移 `-1.5`，再触及 x 面，整步时间 `t=2/3`。身份次序应为 `[y面,x面]`。这可替换原来不可能撞到 y=0 的输入。
- **正常贴墙滑动不应标卡住**：平面法线 `+X`，球心 `(r,0,0)`，纯切向位移 `(0,0,2)`，预期球心到 `(r,0,2)`，没有向内穿透，`stuck=False`。
- **盒角标注**：在扩张 AABB 角落邻域构造精确点到原盒最近点距离作为对照；若保守盒算法早报，记录为预期假阳性/精度限制，不篡改 oracle 成“精确接触”。
