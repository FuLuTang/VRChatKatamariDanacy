# T49 独立测试对象规格（未搭建）

对象名建议：`GroundContactLab`；状态 `SPEC_ONLY / NOT BUILT`。只供Lead审批后由一个Windows Unity集成操作者在隔离测试场景创建；本离线worker没有Unity/MCP。

## 场景 / 读数

- 画一条有颜色/标签的世界 +X、+Y、+Z 箭头；有球芯球面、独立代理点/杆端点、水平平面与非轴对齐斜面。
- 面板读数：当前输入矩阵9项与正交/determinant检查；核心半径 `r`、法线/原始偏置 `(n,d)`、当前中心、当前支持 `h`、目标法线坐标 `d+h`、修正前后中心向量、抬升/下降限幅与速度扰动限幅标志。必须明确 `centerNormalCoordinate` 不是world-Y，`planeAnchor` 不是精确接触点。
- 坐标门探针：显示单位姿态三箭头；手动读取Unity `Quaternion.AngleAxis(+90°, Vector3.up) * Vector3.forward`、逆旋转及局部↔世界非对称点。将观察值与Python主机方向算例并列；差异不得自动取反或隐藏。

## 操作、失败标志与复位

1. `Reset` 恢复核心半径、姿态、平面、球心、代理点和限幅参数到场景默认；清空上一次错误/读数缓存。
2. `Evaluate` 只运行一次纯数值参考，不推进Unity `Rigidbody` 或全局时间。
3. 正常：空代理给 `h=r`；附加向下杆端后 `h` 上升；增大核心半径后突出量下降；移除端点后 `h` 降回当前几何；设置drop cap后中心分步下降。
4. 斜面：输入非单位法线与对应偏置；确认偏置同步归一化，中心只沿单位法线移动且保留切向分量。
5. 错误：矩阵错形/非正交/镜像/NaN、零法线、NaN代理点应触发红色 `INPUT REJECTED`，不显示上次结果冒充成功；再次Reset后恢复正常输入。
6. 失败依据：任一支持数/坐标超解析期望、公示投影沿world-Y而非法线、抬升/下降超限、无效输入被默默接受、坐标探针与宿主侧未经解释地声称一致，都标红 `FAIL` 并保留错误输入摘要。

## 物理隔离 / 验收界限

- 对象不添加 `Rigidbody`、Collider、Trigger、Udon事件或玩法层；测试平面仅用网格/线框显示，不参与碰撞。
- 不写球运动，不生成代理，不连Sweep/PVP/网络/账本，不接正式场景。坐标探针只是实验，不代表Udon编译。
- 当前该对象、Unity编译、UdonSharp ProgramAsset、Unity运行均 `NOT_RUN`；本规格不是已搭建证据。
