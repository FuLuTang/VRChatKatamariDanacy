# 真人输入与舒适测试安全边界

本清单用于未来经用户安排的T05体验；不是医疗建议、医学筛查或舒适性认证。稳定地平线、低幅移动或其他设计措施均不能保证无人晕动或不适。

## 自愿参加与知情

- 由参与者自行选择是否参加PCVR A、PCVR B或Desktop测试；可以跳过任何动作、随时暂停或退出，不影响账号、关系或其他游戏权益。
- 开测前简要说明实验目标、会操纵的设备/输入、可能出现的视觉移动/手臂疲劳、数据记录范围、退出方法及意外恢复步骤；允许参与者提问并明确同意后才开始。
- 使用不含身份信息的参与者代码。除非另有单独明确同意，不录音/录像、不记录账号、姓名或与测试无关的个人/健康信息；对外共享证据前由用户审查并去标识。
- 不把先前通过/继续玩当作本次同意；每次会话均可重新选择。

## 开始前的安全检查

- 确保真实房间内活动空间安全、没有易碰撞物；参与者佩戴设备舒适，控制器腕带等按设备建议使用。非VR Desktop参与者也应可随时暂停。
- 观察员在可沟通的位置，知道如何暂停实验并指引参与者摘下头显/离开Station。确认退出按钮、平台Respawn的人工流程和设备安全回退方式可用；若退出/恢复尚未验证，不开始真人移动测试。
- 先做空场景或低速、短时、无竞争风险的输入检查；每次仅改变一个输入模式/转向设定。未经同意不触发冲撞、吞噬、强制传送或高速度道具。
- 记录测试前玩家可恢复设置快照与由谁/什么组件负责恢复。不得因设置读取不明而覆盖玩家偏好；无法确认安全恢复时停止并先解决门禁。

## 必须停止的条件

- 参与者报告任何程度的晕动、恶心、头痛、眼部不适、失衡、焦虑、手臂/肩颈疼痛或明显疲劳；出现含糊/犹豫的求停表达也立即停止。
- 参与者失去舒适追踪、无法安全控制真实身体，出现硬件/软件异常、镜头强制滚转/快速位移、卡在Station、输入无法归零，或无法执行退出/恢复。
- 参与者要求暂停、摘下设备、退出某项动作或结束会话。

停止后：立即停止游戏移动/输入，不要求“再坚持一轮”确认；协助参与者按其意愿摘设备、坐下/离开实验区或结束会话。未经参与者主动同意，不自动重试或继续同一 session。只记录必要的事件、复现条件和停止时间点，不诊断症状；是否继续由参与者日后自行选择。

## 设计原则与报告

- 默认先用较低强度、短时段、固定地平线；避开非必要垂直加速、强制视角旋转和镜头抖动。任何数值强度/时长须由主管和用户在真实实验前确定，本文件不设人体安全阈值。
- A模式检查胸前固定轮廓、有限水平行程和可调校准是否减少伸臂疲劳；不强制手臂过肩或保持伸直。提供左右互换/重新校准的选择（如实现）。
- B/PC检查同一运动意图是否在不同设置下可理解；右摇杆与原生Comfort Turning冲突时以停止测试、记录问题为先，不要求参与者适应不一致行为。
- 主观舒适度是参与者自述，不等同医疗结论、普遍用户结论或“不晕”证明。报告需分开记录事实观察、参与者自愿反馈、停止/退出情况、硬件环境与未测项；不得用未停止来推定舒适。
- 测试数据仅按用户批准的用途处理；公开视频/宣传、用户/Avatar影像、声音或健康相关内容需另行明确授权，测试同意不等于宣传许可。
