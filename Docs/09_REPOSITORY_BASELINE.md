## 2. 当前玩法理解

- PCVR/Desktop、2–4人休闲PVP，1人练习，Quest不在首版。
- 收集 -> 确认体积 -> 风险成长/吞噬 -> 交存安全积分 -> 缩回球芯 -> 继续收集。
- 时间到按已交存积分排序；未交存资源不自动兑换；免费初始球芯不能刷分。
- A是固定轮廓归中件+平面限位活动件；B是摇杆稳定追尾；PC采用普通移动/观察输入。
- 球运动、球芯缩放、视觉滚动、附着树与FollowRig分层。Avatar不参与玩法碰撞，镜头不继承球滚转。
- 本地吸附可精确、远端装饰可近似；共享判定半径与确认账本必须一致。
- 单槽磁铁/火箭，Jump上升沿使用，无额外经典冲刺。退出和Respawn恢复玩家设置。
- 野餐先做一图两人纵切片，玩具房第二张，夜市可选。
- 免费完整玩法，永久纯外观商品；商家资格未知，收费不得提前开启。

5. **32方向、180秒、1.35尺寸比等均为原型建议**，不是原作还原值或性能数据。
6. **许可未指定**：不自动添加MIT/其他开源许可；第三方资源需逐项授权与分发审查。
7. 导入器为本次附件来源定位的一次性工具，使用独占创建，不能覆盖已有文件；今后版本更新需显式迁移，不重复运行它覆盖当前文档。
