# T50 独立测试对象规格（未搭建）

对象名建议：`RadialProxyLab`；状态 `SPEC_ONLY / NOT BUILT`。T50对象单独建，不复用/改写T49或正式玩法场景。

## 读数布局

- 显示32条固定方向线段，每个方向标索引、单位方向和当前支持长度；对比球芯半径与 `max(0,l-r)` 突出量。
- 列表显示每个附着实例稳定键/世代、端点数量、候选槽、每次add/remove/rebuild的受影响方向数和操作结果。
- 显示全量快照哈希/对比表：incremental与ledger rebuild的32支持值和候选排序；长度端点显示 `p=d*l` 三分量。
- 坐标探针独立显示世界 +X/+Y/+Z；以Unity正Y 90°角旋转实际读取前向轴，并与host Hamilton参考对照。不允许只改坐标手性标签。

## 交互、失败和reset

1. `Reset` 生成默认核心半径/32方向空壳，清除贡献、候选、计数与错误灯；验证32个支持值全等于核心半径。
2. `Attach A` / `Attach B` 输入相同单位方向端点，各贡献2m和4m；沿选定方向读到4m。`Detach B`后读到2m，再移除A回到核心半径。此读数应证明保留次大贡献而非只维护单调max。
3. 候选容量选四并挂满；第五个应显示明确失败原因，不替换原候选。移除一个再加新候选应成功；候选ID按ordinal稳定排序。
4. `Rebuild from confirmed list`反转ledger输入顺序，32方向支持值与候选序列不变；减少核心半径后全量重建，不能仅缩放旧支持值。
5. 失败灯：重复/空身份、空端点、NaN/无穷端点、零/无效四元数、负长度/非单位方向、候选满额、重建部分失败，均为红色`REJECTED / STATE UNCHANGED`。失败后读快照必须与操作前一致。
6. 屏幕操作不输入可争抢定义ID、不运行正式账本。仅调用纯数值草稿；不消费拾取收益。

## 物理隔离 / 验收界限

- 线段/端点仅作Gizmo/线框显示；无Collider、Trigger、Rigidbody、真实Mesh扫描、Udon事件、Renderer budget或玩法碰撞。
- Unity quaternion方向实测、UdonSharp编译、性能与客户端一致性都不在Linux草稿证据内；本规格不是已建对象或验收通过。
