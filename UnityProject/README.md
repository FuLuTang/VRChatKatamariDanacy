# Unity project placeholder

本目录预留为 Unity 工程根，不是已经可运行的 Unity 项目。

T00 开始前需确认：
1. Unity执行机器已确定为用户的Windows PC，用户负责初始化；Windows工程绝对路径待回执，默认建议Windows仓库下的本目录。详见 [Windows初始化清单](<../Docs/10_WINDOWS_UNITY_SETUP.md>)。
2. 开工时复核官方支持的 Unity 版本；设计包记载 2022.3.22f1，但尚未重新核实。
3. 通过 VRChat Creator Companion 创建/接入 Worlds 项目，记录精确 VRCSDK、UdonSharp 及包版本。
4. 用 Unity 生成真实 Assets、Packages、ProjectSettings、场景及 .meta，不手工伪造 GUID 或包锁。
5. 记录编译与 Build & Test 证据后再评审 T00。

未探测远端机器；当前仅确认本机 PATH 中未找到 Unity 可执行文件，不等于证明机器未安装 Unity。

不要在仓库根打开 Unity。Unity 缓存和构建忽略规则覆盖本目录，真实资产及 .meta 必须提交。
