# T54 Sweep 边界（DRAFT）

接口未冻结；仅处理球形环境接触近似，不参与运动积分、T49支持值或T50代理。

## 输入 / 输出

- 输入有限起点 `x`、步位移 `Δx`、非负球半径、障碍数组、正整数接触预算、非负分离epsilon。当前点/长度只是同一调用者单位，单位尺度仍待T06。
- `Plane(normal,offset)`表示允许半空间 `dot(n,p)>=offset`；若n非单位，offset一起除以`|n|`。
- `Box(min,max)`为轴对齐盒。先将AABB各面按球半径扩张，再做 slab sweep。该保守近似在角落是方形外扩，不是精确sphere-box round-corner距离算法。
- `Contact.time`为原始整个步位移 `[0,1]` 参数；接触按TOI和输入障碍索引排序，记录球心、近似特征点、自由侧法线、障碍索引与嵌入深度。
- 返回最终位置、未消耗位移、剩余方向、接触序列、`blocked`与`stuck`。

## 嵌入和状态语义

- 即使 `Δx=0`也必须测试初始几何；半空间嵌入沿自由法线推出，深盒内球心推出到扩张AABB最近自由面，推出距离是实际面距+epsilon，不只是一个epsilon。
- `blocked`仅表示接触正常消耗掉请求运动（全部剩余分量被法线阻挡），不是求解失败。
- `stuck`只表示求解无进展、接触预算耗尽仍有未处理位移，或最终几何验证仍嵌入。若一面墙把法向速度清为0但求解有效，应`blocked=True,stuck=False`。纯切向滑墙没有blocked/stuck。
- 输入/中间值坏时抛`ValueError`；没有返回“伪成功”。分离偏置、近零阈值仍是占位。

## 未解 / 移植

极薄双面墙、完全对称凹角、不可行窄通道、多个反向约束和预算耗尽可能仍有残余；调用方必须检查`stuck`与剩余量。扩大AABB角误报是明示限制。未做Unity物理/Udon/网络；本算法点积与方向处理不代表Unity Quaternion/Cross对拍（本层未使用Cross）。
